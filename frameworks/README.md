> **★这里是深度资料，不是入口。**

> 这个目录是升档之后、需要逐条查章程时才进来的。
>
> **另：「至少两扇窗，沟通和干活分开」这一条写在仓根四份的开头，
> 本目录各份默认它已成立。**

这三套框架不是「简版 / 标准版 / 豪华版」。它们是**三种不同的失败模式**的解药：

| | 小型 | 中型 | 大型 |
|---|---|---|---|
| 规模 | 1 人 + 2 扇窗（策划+工位） | 1 人 + 3–5 个固定位 | 1 人 + 十几个位 + 员工池 |
| 它防的失败 | **换窗就失忆** | **没人复核，自述当真** | **谁在做什么说不清** |
| 工单台 | 不要 | 单机版 | 全套（含服务端） |
| 任务书档位 | 不分档 | 甲 / 丙两档 | 甲 / 乙 / 丙三档 |
| 有没有独立复检 | 没有（你自己就是） | 有，但兼职 | 有，且**独立于指挥链** |
| 一天要花多少管理时间 | ~0 | 20–40 分钟 | 1–2 小时 |

**选错档的代价是不对称的。**
小项目上大框架 → 你一天有一半时间在填表，项目死于摩擦。
大项目上小框架 → 前两周飞快，第三周开始每天都有「这个谁在做？」「这个做完了吗？」
「这个昨天不是修好了吗」，然后你花两周做考古。

**拿不准就往小了选。** 升档比降档容易得多：升档是加东西，降档要把已经长在流程里的表格拔掉。

---

## 三个判据（任意两条中，就往上走一档）

1. **你能不能在脑子里记住「现在有哪几件事在办」？**
   记不住了 → 至少中型。
2. **有没有出现过「我以为它做完了，其实没有」？**
   出现过一次以上 → 至少中型（你需要的是复核，不是更好的模型）。
3. **两扇窗有没有改过同一个文件 / 抬过同一个号？**
   有 → 大型（你需要的是并线次序，不是更清楚的分工）。

反过来，三条都不中却上了大型框架，你会在第四天开始偷偷跳过流程——
而**被偷偷跳过的流程比没有流程更坏**，因为台面上还写着它在跑。

---

## 三档共用的四条底线

档位再小，这四条都不许省。它们是这整套东西的地基：

1. **自述不算数。** 「我做完了」和「我验证过了」是两句话，后者要给出命令与原样输出。
2. **一个事实只存一处。** 要抄的时候先问：那份抄件过期了谁会发现？
3. **写下来的东西要能回指。** 每条结论都该说得出是从哪来的（哪次运行、哪个文件、哪句话）。
4. **闸只拦「活没做好」。** 拦「字没写对」的闸一律降级成记一行、继续做。
