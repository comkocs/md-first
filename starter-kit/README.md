## 为什么要有这一关

AI 窗口的默认行为是**立刻开始做**。你说「做个后台管理系统」，
它三十秒内就给你建好目录、装好框架、写出十二个文件——
然后你看着那十二个文件，发现没有一个是你想要的。

这不是它的问题。**是因为它问不出「什么算做完」，而你也还没想清楚。**

这一关只干一件事：**在写第一行代码之前，把「做完」这件事变成一句能验的话。**

## 三个问题

```
1. 你要什么？      —— 一句话，名词，不是形容词
2. 给谁用？        —— 具体到一个人在什么场合下打开它
3. 什么算做完？    —— 一句能验的话：我点哪里 / 跑哪条命令，看见什么
```

第 3 个问题是关键。它答不上来的时候，**不许开始写代码**。

## 答不上来怎么办：DEMO 先行

答不出第 3 题，几乎总是因为你脑子里还没有那个画面。
这时候写代码是最贵的探索方式——**先出一页可点的 DEMO**：

- **半小时之内**能点的一页 HTML，纯静态、假数据、不连后端；
- 它的作用**不是原型**，是**提问工具**：你点两下就会说「不对，这里应该是……」；
- 那句「不对，这里应该是……」才是真需求，而它在你看见东西之前说不出来。

骨架在 [`demo-template/`](demo-template/)，双击 `index.html` 就能看。
改法见 [`DEMO先行.md`](DEMO先行.md)。

★**DEMO 是一次性的，做完就扔。** 拿 DEMO 当代码基础往下长，
你会背着一堆为了"先看看效果"写的假数据结构走很远。

## 这一关之后

| 三个问题都答上了 | 去 [`../frameworks/`](../frameworks/) 选档，建第一张单 |
|---|---|
| 答不上第 3 题 | 出 DEMO → 聊 → 再回来答第 3 题 |
| 连第 1 题都答不上 | 你要的不是做东西，是想清楚要做什么。**先别开窗。** |
